## 🧹 Limpieza y preparación de datos con Python

En este proyecto se ha realizado un proceso completo de **preparación y limpieza de un conjunto de datos utilizando Python en Google Colab**, con el objetivo de obtener un dataset fiable, estructurado y preparado para su posterior análisis.

### 📥 1. Importación y exploración inicial

En primer lugar, se ha realizado la **importación del conjunto de datos** y una exploración inicial de su estructura y contenido.

Durante esta fase se han analizado aspectos como:

* Estructura y dimensiones del conjunto de datos.
* Tipos de variables y columnas disponibles.
* Valores y categorías presentes en las variables.
* Identificación inicial de valores nulos y posibles inconsistencias.
* Exploración general de los datos.

### 🧹 2. Diagnóstico y limpieza de los datos

Una vez explorado el conjunto de datos, se ha llevado a cabo un proceso de **diagnóstico y limpieza**, aplicando diferentes técnicas para mejorar su calidad y consistencia.

Entre las tareas realizadas se incluyen:

* Identificación y eliminación de **registros duplicados**.
* Detección y tratamiento de **valores nulos**.
* Sustitución de valores nulos por **"No consta"** cuando correspondía.
* Revisión y corrección de **columnas y valores inconsistentes**.
* Comprobación y ajuste de los tipos de datos.
* Filtrado y selección de registros según determinados criterios.
* Revisión de las categorías y valores únicos de las variables.

Estas operaciones permiten disponer de un conjunto de datos más **limpio, coherente y homogéneo**, reduciendo posibles problemas durante las fases posteriores de análisis.

### ✅ 3. Validación y exportación

Finalmente, se ha realizado una **validación del conjunto de datos resultante**, comprobando que las transformaciones y procesos de limpieza se han aplicado correctamente.

Una vez validado, el conjunto de datos limpio queda **preparado para su posterior análisis y explotación**, facilitando el trabajo con técnicas de análisis de datos y visualización.
